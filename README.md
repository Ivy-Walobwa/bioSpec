# bioSpec

<!-- badges: start -->
<!-- badges: end -->

The goal of bioSpec is to visualize biodiversity data on a map and
timeline.

## Installation

You can install the development version of bioSpec from
[GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("Ivy-Walobwa/bioSpec")
```
